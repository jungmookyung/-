# 72시간 런치 플랜

> 전제: "AI가 혼자 100만원을 벌어온다"는 건 광고 서사입니다. 현실은
> **상품·카피·계획은 자동화하고, 계정·결제·게시는 본인이** 하는 구조예요.
> 이 플랜은 그 현실에서 첫 매출을 내는 데 초점을 둡니다.
>
> 숫자 예시: 39,000원 상품이면 **26개**, 89,000원이면 **12개**면 100만원.
> 첫 목표는 100만원이 아니라 **"첫 결제 1건"**입니다. 1건이 나면 나머지는 반복.

---

## Day 0 (0~4시간) — 상품을 '내 것'으로 만들기

- [ ] `guide/ai-automation-guide.md`를 읽고, 내 경험/사례 3개를 추가.
- [ ] 표지에 **내 이름·브랜드·연락처** 삽입. (킷의 자리표시자 교체)
- [ ] 가이드를 PDF로 내보내기 (아래 "PDF 만드는 법" 참고).
- [ ] 가격 결정: 시작가는 **부담 없는 선(9,900~39,000원)** 권장.
      → 팔리면 1권마다 조금씩 올리는 '희소성' 규칙도 선택지.

## Day 0 (4~8시간) — 채널·결제 셋업

- [ ] `channel-setup.md`대로 **판매 플랫폼 1개** 가입 + 상품 등록 + 링크 확보.
- [ ] **유입 채널 1개** 정리(프로필·소개·고정 링크).
- [ ] 무료 웹툴 링크를 프로필에 걸기.

## Day 1 — 이야기로 알리기 (판매글 X, 회고글 O)

- [ ] `sales-copy.md`의 **후킹 문장 6종** 중 3개로 글 3개 작성.
- [ ] 글 구성: 문제/실패담 → 뭘 알게 됐나 → (댓글에) 무료 툴/상품 링크.
- [ ] 카드뉴스 1장 첨부(문구는 sales-copy.md 참고).
- [ ] 반응 좋은 글에만 유료 안내 댓글 달기.

## Day 2 — 반복 + 소통 (여기서 매출이 붙습니다)

- [ ] 어제 글 중 **조회/댓글 높은 것**을 변형해 재게시.
- [ ] 달린 댓글에 **전부 답글**(소통이 노출을 키움).
- [ ] "첫 구매 후기"가 생기면 그 사실 자체를 콘텐츠로. ("방금 첫 결제가 나왔다")
- [ ] 상세페이지가 밋밋하면 이미지형으로 보강.

## Day 3 — 정리 + 다음 사이클

- [ ] 어떤 훅/채널이 반응 좋았는지 기록.
- [ ] 안 팔렸다면: 가격↓ 또는 타겟 좁히기 또는 무료 미끼 강화 중 **하나만** 바꾸기.
- [ ] 다음 상품 후보 1개 적기(같은 방식 반복).

---

## 안 팔릴 때 점검 순서 (위→아래로 하나씩)

1. **본 사람이 있나?** 조회 자체가 적으면 → 채널/훅 문제. 글을 더, 다르게.
2. **클릭했는데 안 사나?** 상세페이지 문제 → 첫 3줄과 "누구를 위한 것"을 강화.
3. **클릭도 없나?** 훅(첫 문장) 문제 → sales-copy.md의 다른 훅으로 교체.
4. **가격 저항?** 시작가를 낮추고, 팔리면 올리는 방식으로.

> 한 번에 하나만 바꾸세요. 그래야 뭐가 효과였는지 압니다.

## PDF 만드는 법 (택 1)

- **가장 쉬움:** `guide/ai-automation-guide.md`를 노션/구글독스에 붙여넣기 →
  꾸미기 → "PDF로 내보내기".
- **마크다운 그대로:** VS Code + "Markdown PDF" 확장, 또는
  `pandoc guide/ai-automation-guide.md -o guide.pdf` (pandoc 설치 시).
- 표지 이미지 1장만 있어도 완성도가 확 올라갑니다.

## 현실적인 기대치 (정직하게)

- 첫 사이클에 100만원을 다 못 채울 수 있습니다. **정상입니다.**
- 진짜 자산은 "판매 링크 + 알리는 채널 + 반복 가능한 상품"이라는 **구조**입니다.
- 이 구조가 서면, 다음 상품부터는 훨씬 빠릅니다. 첫 1건에 집중하세요.
