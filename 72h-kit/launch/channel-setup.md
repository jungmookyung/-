# 판매 채널 셋업 가이드 (계정이 하나도 없을 때)

> 목표: 오늘 안에 "결제받을 곳 1개 + 알릴 곳 1개"를 만든다.
> 계정 생성·결제·게시는 **반드시 본인이** 하세요. (AI가 대신 로그인/결제 X)

---

## 1단계 — 결제받을 곳 (판매 플랫폼) 하나 고르기

디지털 상품(전자책·템플릿)은 아래 중 하나면 충분합니다. 한국 기준 추천 순서:

| 플랫폼 | 특징 | 추천 상황 |
|---|---|---|
| **크몽 / 탈잉** | 유입이 이미 있음, 수수료 높음 | 초기 노출이 급할 때 |
| **라이트펀딩·latpeed류** | 링크 하나로 판매, 심플 | 내 SNS로 유입 보낼 때 |
| **스마트스토어** | 신뢰도·검색 유입 | 사업자등록 있을 때 |
| **부스트·페이히어·토스페이먼츠 링크** | 결제 링크만 | 가장 빠른 시작 |
| **Gumroad** | 해외, 셋업 5분 | 영어권/글로벌도 노릴 때 |

**가장 빠른 시작(오늘):** 계정 만들기 → 상품 등록(제목·가격·설명·파일 업로드)
→ 판매 링크 복사. 파일은 이 킷의 PDF/자료를 본인 것으로 다듬어 올립니다.

체크리스트:
- [ ] 플랫폼 1개 가입 (본인 이메일)
- [ ] 정산 계좌 등록
- [ ] 상품 등록 + 가격 설정
- [ ] 판매 링크 확보

---

## 2단계 — 알릴 곳 (유입 채널) 하나 만들기

물건은 "본 사람"만 삽니다. 아래 중 이미 익숙한 것 1개부터:

- **스레드/인스타:** 짧은 글·카드뉴스에 강함. 후킹 문장으로 시작.
- **블로그(네이버/티스토리):** 검색 유입. 상세 후기·가이드형 글에 강함.
- **카카오 오픈채팅:** 주제방 개설 → 관심자 모으기 → 공지로 안내.
- **커뮤니티 글:** 관련 카페/디스코드에 "후기·경험" 형태로 (광고 금지 규칙 확인).

원칙(중요):
- **본문에 판매 링크를 바로 넣으면 노출이 죽는 플랫폼이 많습니다.** 링크는
  댓글/프로필로 내리고, 본문은 "이야기"로.
- **판매글보다 회고·경험담이 더 잘 읽힙니다.** "이렇게 만들었다/이래서 실패했다"가
  "사세요"보다 강합니다.

체크리스트:
- [ ] 채널 1개 선택 + 프로필/소개 정리
- [ ] 프로필 또는 고정 위치에 판매 링크
- [ ] 첫 글 3개 예약(플랜 참고)

---

## 3단계 — 무료 미끼(리드마그넷) 걸기

무료로 하나 주고 신뢰를 얻은 뒤 유료로 안내합니다. 이 킷에 이미 있습니다:

- **무료 웹툴** = "AI 업무지시서 생성기" (배포된 링크를 그대로 공유)
- 무료로 써본 사람에게 "더 깊은 10종 지시서 + 가이드는 여기" 로 유료 안내.

---

## 하지 말 것 (신뢰·계정 보호)

- 가짜 후기/자화자찬 댓글 만들기 → 계정 정지·신뢰 붕괴 위험.
- 같은 글 도배 → 스팸 처리.
- 근거 없는 "무조건 벌린다" 문구 → 환불·분쟁·법적 리스크.
- 타인 자료 무단 사용 → 저작권 문제.

정직하게, 실제 가치를 주는 방향이 결국 가장 빠릅니다.
