# 업무별 지시서 10종 — 복붙해서 바로 쓰는 프롬프트 킷

> 사용법: 아래 지시서를 복사 → `[대괄호]` 부분만 내 상황으로 바꾸기 →
> AI에 붙여넣기. 각 지시서는 **역·맥·작·형·완**(역할·맥락·작업·형식·완료기준)
> 구조로 되어 있습니다.

---

## 1. 고객 문의 답변 초안

```
당신은 10년차 고객상담 팀장입니다.
[업종/제품: 예) 수제 캔들을 파는 온라인 쇼핑몰]의 고객 문의에 답합니다.

아래 문의에 대한 답변 초안을 작성하세요.
문의: "[고객 문의 원문 붙여넣기]"

형식:
- 존댓말, 3문단 이내, 250자 이내
- 1문단: 공감/사과 → 2문단: 해결/안내 → 3문단: 다음 행동 1개 제시
- 확실하지 않은 정보는 [확인 필요]로 표시

완료 기준: 규정 위반 없음, 고객이 다음에 뭘 하면 되는지 명확함.
```

## 2. 환불·교환 안내 (규정 준수형)

```
당신은 규정을 지키면서도 친절한 CS 담당자입니다.
우리 환불 규정: [규정 요약 3줄 붙여넣기]

고객 요청: "[요청 원문]"

이 요청이 규정상 (가능/부분가능/불가) 중 무엇인지 먼저 한 줄로 판단하고,
그 판단에 맞는 정중한 안내문을 작성하세요.
불가일 경우 대안 1개를 반드시 제시합니다.
형식: 존댓말, 200자 이내. 금액/기한 등 숫자는 [ ]로 비워두어 내가 채우게.
```

## 3. SNS 게시글 초안 (후킹 문장 포함)

```
당신은 전환율 높은 SNS 카피라이터입니다.
주제: [오늘 알릴 내용]
타겟: [누구에게: 예) 1인 자영업자]

게시글 초안 3개를 서로 다른 첫 문장(훅)으로 작성하세요.
훅 유형: (1) 숫자/결과 (2) 의외의 사실 (3) 공감되는 고백
형식: 각 150자 이내, 해시태그 3개, 마지막 줄에 행동유도 1문장.
링크는 본문에 넣지 말고 [댓글 링크]라고만 표시.
```

## 4. 블로그/뉴스레터: 개요 → 초안

```
당신은 실용 정보 블로그 작가입니다.
주제: [주제]. 독자가 얻어갈 것: [핵심 이득 1가지].

먼저 소제목 5개로 개요를 짜고, 내가 "진행"이라고 하면 본문을 씁니다.
톤: 쉬운 말, 문단당 3문장 이내, 과장 금지.
완료 기준: 독자가 읽고 바로 실행할 수 있는 행동이 최소 1개 포함.
```

## 5. 견적서·제안 요약

```
아래 긴 제안/견적 내용을 고객이 5초 안에 이해하도록 요약하세요.
내용: "[원문 붙여넣기]"

형식:
- 한 줄 요약(무엇을/얼마에/언제까지)
- 항목별 표: 항목 | 내용 | 금액
- 마지막에 "다음 단계" 1문장
숫자는 원문 그대로. 없는 정보는 지어내지 말고 [미정] 표기.
```

## 6. 회의록 3줄 요약 + 할 일 추출

```
아래 회의 내용을 정리하세요.
내용: "[녹취/메모 붙여넣기]"

출력:
1) 3줄 요약
2) 결정사항 목록
3) 할 일 표: 담당 | 할 일 | 기한
발언자가 불명확하면 [담당 미정]으로 표시.
```

## 7. 리뷰/후기 분류 + 대표 3개 추출

```
아래 고객 후기들을 분석하세요.
후기: "[여러 개 붙여넣기]"

출력:
- 긍정/중립/부정 개수
- 가장 많이 나온 칭찬 3개, 불만 3개
- 홍보에 쓸 만한 대표 후기 3개(원문 그대로 인용)
개인정보(이름 등)는 이니셜로 마스킹.
```

## 8. 상세페이지 카피 (문제→해결→행동)

```
당신은 정직하게 잘 파는 카피라이터입니다. 과장·허위 금지.
상품: [상품명 / 무엇을 해주는지 한 줄]
타겟의 진짜 고민: [고민 1~2개]

구조로 작성:
1) 문제 공감 (2~3문장)
2) 이 상품이 그걸 어떻게 푸는지 (핵심 3가지)
3) 이런 분께 / 이런 분껜 비추천 (기대치 정렬)
4) 지금 시작하는 법 (행동 1개)
형식: 소제목 있는 섹션. 근거 없는 "최고/1위" 표현 금지.
```

## 9. 이메일 정중화 / 축약 변환

```
아래 초안을 [정중하게 / 더 짧게 / 더 단호하게] 다듬으세요.
초안: "[원문]"
받는 사람: [관계: 예) 처음 연락하는 거래처]
형식: 제목 1줄 + 본문 5문장 이내. 핵심 요청은 굵게 표시할 위치 표기.
```

## 10. 데이터 표 정리·형식 변환

```
아래 지저분한 데이터를 깔끔한 표로 정리하세요.
데이터: "[붙여넣기]"

규칙:
- 열: [원하는 열 이름들]
- 빈 값은 [빈칸]으로, 임의로 채우지 말 것
- 중복 행은 제거하고 몇 개 제거했는지 알려줄 것
출력: 마크다운 표 + CSV 두 형식.
```
