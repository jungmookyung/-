# 바로 올리는 홍보 게시글 팩 (복붙용, 완성문)

> 이건 "템플릿"이 아니라 **거의 완성된 글**입니다. 그대로 올리거나, 말투만 살짝 바꾸세요.
> `[링크]`에는 무료 계산기 링크나 판매 링크를 넣고, **본문 대신 첫 댓글에** 다는 걸 권장합니다.
> 원칙: 판매글보다 **경험담·정보글**이 훨씬 잘 읽힙니다. 근거 없는 수익 보장 문구는 넣지 마세요.

---

## A. 스레드 / 인스타 — 경험담형 (첫 문장 훅)

### A-1
```
5만 원짜리 팔았는데 통장엔 8천 원.
처음엔 계산을 잘못했나 했는데, 아니었어요.

스마트스토어 수수료, 광고비, 배송비, 부가세.
하나씩 빼보니 마진은 원래 그만큼이었던 겁니다.
그동안 "감"으로 가격을 정하고 있었더라고요.

그래서 팔기 전에 미리 계산부터 하기로 했습니다.
원가랑 채널만 넣으면 1개당 진짜 남는 돈이 나오는 계산기.
필요하신 분 있을까 봐 댓글에 링크 둘게요.
```

### A-2
```
광고 켜니까 매출은 늘었는데 왜 남는 게 없지?

ROAS만 보고 있었던 게 문제였어요.
정작 "이 상품 1개 팔면 얼마 남는지"는 계산해 본 적이 없었거든요.

광고비까지 넣고 계산해보니
어떤 상품은 팔수록 손해였습니다. 소름.

가격/마진 계산기 하나 만들어서 쓰고 있는데,
같은 고민 하신 분들 써보시라고 공유해요. (댓글 링크)
```

### A-3 (채널 비교 훅)
```
같은 상품인데 스마트스토어랑 쿠팡이랑 남는 게 다릅니다.

수수료가 5.5% vs 10.8%니까요.
29,900원짜리 기준으로, 채널만 바꿔도 순이익이 2천 원 넘게 차이 나더라고요.

"이 상품은 어디서 팔아야 제일 남나"를
한 화면에서 비교하는 계산기를 만들었어요.
링크는 댓글에. 무료입니다.
```

## B. 네이버 카페 / 커뮤니티 — 정보 공유형 (제목 + 본문)

> ⚠️ 카페마다 홍보 규칙이 다릅니다. **광고 금지 게시판은 피하고**, 정보/노하우
> 게시판에 "직접 만들어 쓰는 도구 공유" 형태로. 링크 규정도 꼭 확인하세요.

**제목:** 팔기 전에 마진 계산하는 습관 (feat. 제가 쓰는 계산기)

```
셀러 3년 차인데, 초반에 제일 많이 한 실수가
"경쟁사보다 조금 싸게"로 가격을 정한 거였어요.

그러다 보니 수수료·광고비·배송비 다 빼면
본전이거나 마이너스인 상품이 꽤 있었습니다.

그래서 지금은 신상품 등록 전에 무조건 마진부터 계산합니다.
- 원가 + 채널 수수료 + 광고비 + 배송비 + (부가세)
- 여기서 남는 게 순이익
- 목표 마진율(예: 25%) 정하고 판매가 역산

계산기 하나 만들어서 쓰고 있는데 설치·가입 없이 됩니다.
혹시 도움 되실까 해서 공유해요. (규정상 링크는 댓글/쪽지로)

다들 마진 잘 챙기시길!
```

## C. 카카오 오픈채팅 — 안내 공지형

```
[공유] 쇼핑몰 마진 계산기 (무료)

안녕하세요! 신상품 가격 정할 때 쓰는 마진 계산기 공유합니다.

✅ 채널(스마트스토어/쿠팡/자사몰) 고르면 수수료 자동
✅ 원가·광고·배송 넣으면 1개당 순이익 즉시
✅ "25% 남기려면 얼마?" 판매가 역산
✅ 채널별 마진 비교까지

설치·가입 없이 링크만 열면 됩니다.
👉 [링크]

수수료율은 예시라 본인 계약 요율로 수정하시면 정확해요.
```

## D. 카드뉴스 문구 세트 (이미지 5장용)

### 세트 1 — "마진의 진실"
1. 5만 원 팔았는데, 남는 건 8천 원?
2. 판매가에서 빠지는 것들 — 수수료·광고비·배송비·부가세
3. 그래서 "감"으로 가격 정하면 위험합니다
4. 원가·채널만 넣으면 → 1개당 순이익 자동 계산
5. 팔기 전에 계산하세요 👉 (댓글 링크, 무료)

### 세트 2 — "어디서 팔까"
1. 같은 상품, 스마트스토어 vs 쿠팡 — 어디가 남을까?
2. 수수료 5.5% vs 10.8%, 순이익이 달라집니다
3. 자사몰은 수수료↓ 하지만 광고비를 따로 봐야 함
4. 채널별 마진을 한 화면에서 비교
5. 내 상품은 어디가 유리한지 확인 👉 (댓글 링크)

## E. 무료 → 유료 전환 멘트 (댓글/DM용)

```
무료 계산기 잘 쓰셨다면,

'쇼핑몰 셀러 킷'도 있어요. 필요하시면 안내드릴게요 🙂
```

## 게시 리듬 (2주 예시)

| 일 | 올릴 것 |
|---|---|
| 1~2일 | A-1, A-3 (스레드/인스타) |
| 3일 | B (카페 정보글) |
| 4일 | 카드뉴스 세트1 |
| 5~6일 | 반응 좋은 글에 대댓글 + A-2 |
| 7일 | C (오픈채팅 공유) |
| 8~10일 | 카드뉴스 세트2, 후기/사용화면 공유 |
| 11~14일 | 잘 된 글 변형 재게시 + E(전환 멘트) |

> 핵심: **매일 하나씩, 링크는 댓글에, 댓글엔 꼭 답글.** 소통이 노출을 키웁니다.
