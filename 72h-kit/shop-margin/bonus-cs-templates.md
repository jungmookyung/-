# 쇼핑몰 CS 답변 템플릿 10종 (복붙용)

> 사용법: 상황에 맞는 답변을 복사 → `[대괄호]`만 내 쇼핑몰에 맞게 수정 → 발송.
> 원칙: **공감 먼저 → 사실/규정 안내 → 다음 행동 1개**. 존댓말, 짧고 명확하게.
> 되돌릴 수 없는 처리(환불 승인·재발송)는 보내기 전에 사람이 한 번 확인.

---

## 1. 배송 지연 문의

```
안녕하세요, [상점명]입니다. 주문하신 [상품명] 배송이 늦어져 걱정되셨죠, 정말 죄송합니다.
확인 결과 [택배사] 물량 지연으로 현재 [상태: 집화/이동 중]입니다.
[예상 도착일: 예) 내일(O/O)] 안에는 받아보실 수 있도록 배송사에 재확인 요청해 두었습니다.
혹시 그때까지 도착하지 않으면 바로 조치해 드리겠습니다. 불편을 드려 다시 한번 사과드립니다.
```

## 2. 단순 변심 반품 요청

```
안녕하세요, [상점명]입니다. 문의 주셔서 감사합니다.
단순 변심 반품은 상품 수령 후 [7]일 이내, 미개봉·미사용 상태에서 가능하며
왕복 배송비 [금액]원은 고객님 부담으로 안내드리고 있어요.
진행을 원하시면 (1) 주문번호 (2) 반품 사유를 남겨주시면 반품 주소와 절차를 바로 보내드리겠습니다.
```

## 3. 불량/오배송 (판매자 귀책)

```
안녕하세요, [상점명]입니다. [불량/오배송]으로 불편을 드려 진심으로 죄송합니다.
이 경우 배송비는 전액 저희가 부담하며, [재발송/전액 환불] 중 원하시는 방법으로 처리해 드리겠습니다.
확인을 위해 상품 상태가 보이는 사진 1~2장만 보내주시면 즉시 진행하겠습니다.
빠르게 바로잡겠습니다.
```

## 4. 품절/재입고 문의

```
안녕하세요, [상점명]입니다. 찾아주셨는데 [상품명]이 현재 품절이라 죄송합니다.
재입고는 [예정 시기: 예) 다음 주 중] 예정이며, 원하시면 재입고 알림을 신청해 드릴게요.
비슷한 상품으로 [대체 상품명]도 있으니 참고 부탁드립니다.
```

## 5. 교환 요청 (사이즈/색상)

```
안녕하세요, [상점명]입니다. 교환 도와드리겠습니다.
[상품명]의 [사이즈/색상] 교환은 재고 확인 후 가능하며, 단순 변심 교환 시 왕복 배송비 [금액]원이 발생합니다.
원하시는 [사이즈/색상]과 주문번호를 남겨주시면 재고 확인 후 절차를 안내드릴게요.
```

## 6. 환불 지연 문의

```
안녕하세요, [상점명]입니다. 환불이 늦어져 답답하셨죠, 죄송합니다.
환불은 반품 상품 회수·검수 완료 후 [영업일 기준 2~3일] 내 처리되며,
카드 결제는 카드사 사정에 따라 [3~5일] 더 걸릴 수 있습니다.
현재 [상태: 회수 완료/검수 중]이며 [예상 완료일]까지 마무리하겠습니다.
```

## 7. 세금계산서/현금영수증 요청

```
안녕하세요, [상점명]입니다. [세금계산서/현금영수증] 발행 도와드리겠습니다.
발행에 필요한 (1) [사업자등록증 사본 또는 사업자번호] (2) 담당자 이메일 을 남겨주시면
[영업일 2일] 내 발행해 드리겠습니다. 이미 결제하신 건은 결제일 기준으로 처리됩니다.
```

## 8. 상품 사용법/사이즈 문의 (구매 전)

```
안녕하세요, [상점명]입니다. 관심 가져주셔서 감사합니다.
[상품명]은 [핵심 스펙/사이즈 가이드 요약]입니다.
[구체 질문]에 대해서는 [답변]이며, 상세 이미지 [n]번째에서도 확인하실 수 있어요.
더 궁금하신 점 있으면 편하게 물어봐 주세요!
```

## 9. 별점 낮은 후기 대응 (공개 답변)

```
소중한 후기 감사합니다. 기대에 못 미쳐 정말 죄송합니다.
말씀해 주신 [문제점]은 저희가 놓친 부분이라 [개선 조치: 예) 검수 강화/상세정보 수정]하겠습니다.
불편 겪으신 부분은 [연락 채널]로 주문번호와 함께 연락 주시면 바로 도와드리겠습니다. 다시 한번 사과드립니다.
```

## 10. 무리한 요구/규정 밖 요청 (정중한 거절 + 대안)

```
안녕하세요, [상점명]입니다. 요청 주신 내용 잘 확인했습니다.
다만 [해당 요청]은 [사유: 예) 개봉·사용 후 단순변심] 에 해당해 규정상 [환불/교환]이 어려운 점 양해 부탁드립니다.
대신 [대안: 예) 부분 적립/다음 구매 할인]으로 도와드릴 수 있는데 괜찮으실까요?
최대한 방법을 찾아보겠습니다.
```

---

## 한 줄 수정 치트시트
| 상황 | 붙일 한 줄 |
|---|---|
| 더 정중하게 | "불편을 드려 죄송합니다"를 앞에 |
| 더 단호하게(규정) | "규정상 ~는 어렵습니다"를 명확히 |
| 화난 고객 | 사과 → 즉시 해결책 → 담당자 직통 안내 |
| 길다 | 핵심 3문장으로: 공감·조치·다음행동 |
