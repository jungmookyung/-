## 판매 방식 3가지 (택1 또는 조합)

1. **무료 미끼 + 유료 번들 (추천 시작법)**
   계산기를 무료로 뿌려 신뢰 확보 → CS템플릿+정리표 묶음을 유료로.
2. **툴 자체 판매**
   계산기+부가자료를 하나의 상품으로. 예시가 9,900~14,900원.
3. **니치 커스텀**
   특정 카테고리(패션/식품/뷰티 등) 셀러 맞춤 버전으로 단가 ↑.

## 런치 체크리스트 (순서대로)

### 1단계 — 상품 마무리 (30분)
- [ ] `landing.html`의 `[대괄호]` 교체: `[내 상점명]`, `[가격]`, `[여기에_내_판매링크]`, `[이메일/카톡]`
- [ ] 계산기에 내 실제 취급 상품으로 숫자 넣어 **결과 화면 녹화/캡처** (홍보 소재)
- [ ] (선택) 계산기 채널 수수료를 내 실제 계약 요율로 수정

### 2단계 — 판매처 개설 (30분~1시간, 본인만 가능)
- [ ] 판매 플랫폼 1곳 가입 (크몽 / 스마트스토어 / 라이트펀딩류)
- [ ] 정산 계좌 등록
- [ ] 상품 등록 + 파일/링크 업로드 + 가격 설정
- [ ] **판매 링크 확보** → `landing.html`에 연결

### 3단계 — 홍보 시작 (매일 10분)
- [ ] 유입 채널 1곳 정리 (스레드/인스타/카페/오픈채팅) — 프로필에 링크
- [ ] `marketing-posts.md`의 게시 리듬대로 **매일 1개씩** 게시
- [ ] 링크는 **본문 대신 첫 댓글**에
- [ ] 달린 댓글에 **전부 답글** (소통이 노출을 키움)

### 4단계 — 반복·개선
- [ ] 조회·클릭·구매 중 어디서 막히는지 확인 (`../launch/72h-plan.md`의 점검 순서)
- [ ] 첫 구매가 나오면 그 사실 자체를 콘텐츠로
- [ ] 한 번에 하나씩만 바꾸기 (훅 / 가격 / 타겟)

## 정직 원칙 (꼭 지키기)
- 근거 없는 "무조건 벌린다 / 최고 / 1위" 문구 금지 → 환불·분쟁·계정정지 리스크.
- 가짜 후기·도배 금지. 실제 사용 화면이 가장 강한 증거.
- 수수료율·부가세는 "예시, 본인 요율로 수정 가능"이라고 밝히면 오히려 신뢰 ↑.
